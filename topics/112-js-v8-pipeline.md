# 1. Тема

**Процесс обработки кода в V8**

---

# 2. Главное в одну фразу

V8 разбирает JavaScript в синтаксическое представление, быстро запускает байткод Ignition и оптимизирует горячий код TurboFan с возможной деоптимизацией.

---

# 3. Суть

> V8 не превращает весь JavaScript сразу в быстрый машинный код. Он разбирает исходный текст, строит внутреннее представление и запускает байткод через интерпретатор Ignition.
>
> Это даёт быстрый старт программы и позволяет увидеть реальные данные. Для часто выполняемых функций движок собирает профиль типов и форм объектов, чтобы ускорять именно наблюдаемый сценарий.
>
> TurboFan может скомпилировать горячую функцию в специализированный машинный код и встроить часть вызовов. Если функция вдруг получает другие типы или форму объекта, прежнее предположение отменяется: код деоптимизируется до общего пути, но остаётся корректным. Поэтому предсказуемость данных полезна в горячем месте, однако пороги и эффект нужно подтверждать профилем, а не угадывать.

---

# 4. Самое главное запомнить

- AST — дерево синтаксической структуры, не машинный код.
- Ignition ускоряет старт: он исполняет байткод.
- JIT сочетает интерпретацию, профилирование и компиляцию «на лету».
- Оптимизация спекулятивна: V8 предполагает типы и формы по наблюдениям.
- Деоптимизация сохраняет корректность, а не является исключением приложения.

---

# 5. Описание

```text
JavaScript → токены → parser/AST → bytecode (Ignition)
                                    ↓ профиль выполнения
                           оптимизированный код (TurboFan)
                                    ↓ предположение сломалось
                                  deopt
```

```js
function add(a, b) {
  return a + b;
}

add(1, 2);      // движок видит числовой сценарий
add('1', '2');  // может потребовать более общего пути
```

Нельзя строить продуктовую оптимизацию на конкретном пороге «N вызовов»: пороги, эвристики и версии V8 меняются. Практический вывод — делать горячий код предсказуемым по типам и формам данных, а производительность подтверждать профилированием.
