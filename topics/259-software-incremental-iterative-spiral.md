# 1. Тема

**Подходы: инкрементная, итеративная, спиральная модели**

---

# 2. Главное в одну фразу

Инкремент отдаёт готовый срез продукта, итерация уточняет тот же продукт целиком, спираль крутит циклы вокруг самого дорогого риска.

---

# 3. Суть

> Инкрементная, итеративная и спиральная модели — способы резать работу во времени. Инкремент отдаёт **готовый срез** (`auth` выкатили, корзины ещё нет). Итерация возвращается к **тому же** продукту: сначала грубый checkout целиком, потом точнее. Спираль Боэма крутит циклы вокруг **риска**: цель → неизвестное → прототип → план следующего витка.
>
> Водопад ломается, когда требования и технология ещё плывут. Нужен ранний рабочий кусок, обратная связь или проверка самого дорогого неизвестного — иначе месяцы уходят в документ, который устареет.
>
> На схеме продукта рисунок разный. Инкремент заполняет куски по `ROADMAP`. Итерация на каждом такте трогает все части, качество растёт. Спираль может начать с платёжного шлюза, а не с «первой фичи» в списке.
>
> Ловушка: «итеративно» часто говорят про нарезку новых фич — это инкремент. Agile обычно и то и другое. Спираль ≠ спринт: без явного риска в центре цикла это просто короткие инкременты.

---

# 4. Самое главное запомнить

- Инкремент: очередной срез **можно выкатить**; соседние части могут быть пустыми.
- Итерация: тот же контур продукта, на такте N он полнее/лучше, чем на N−1.
- Спираль: порядок срезов задаёт **риск**, не удобный порядок в `ROADMAP.md`.
- Команда часто делает оба: новая фича (инкремент) и шлифовка старой (итерация).
- Спринт без выбора риска — не спираль, а короткий инкремент или итерация.
- Водопад «сначала всё спроектировать» ломается на неизвестном шлюзе, нагрузке, сценарии.

---

# 5. Описание

```text
checkout:  [ Auth ]  [ Cart ]  [ Pay ]

инкремент   ✓ пусто пусто  →  ✓ ✓ пусто  →  ✓ ✓ ✓     готовые срезы по roadmap
итерация    ~  ~  ~        →  ≈  ≈  ≈    →  ✓ ✓ ✓     тот же контур, качество ↑
спираль     пусто пусто ⚡Pay → ⚡Auth … →  ✓ ✓ ✓     сначала самый дорогой риск
```

`⚡` — текущий риск цикла, не «следующая строка в бэклоге».

## Инкремент

Каждый такт добавляет **законченный** кусок: его можно показать, продать, включить за флагом. Пустые соседние куски — норма. Типичный артефакт — `docs/ROADMAP.md` с `v0.1` / `v0.2`.

Цена: если первый срез выбран «по удобству», а не по ценности, две недели уходят в админку, а платёж так и не проверен.

## Итерация

Контур продукта появляется рано (все три экрана-заглушки), затем каждый проход уточняет **все** части: валидация, UX, ошибки. Это не «ещё одна фича», а более точная версия того же checkout.

Цена: без инкремента легко крутить полировку и ни разу не выкатить рабочий срез.

## Спираль

Цикл Боэма: цели витка → риски и прототип под них → разработка/проверка → план следующего. Для checkout первый риск часто **шлюз**, не логин: цикл 1 делает песочницу `Pay`, цикл 2 — сессии `Auth`, цикл 3 — `Cart`.

Артефакт — `docs/risk-register.yml`: что неизвестно, какой прототип это снимет, какой виток следующий.

## Что не путать

| Слово в быту | Часто имеют в виду | Точнее |
| --- | --- | --- |
| «итеративно» | по чуть-чуть новых фич | инкремент |
| «по спринтам» | короткие циклы | инкремент и/или итерация |
| «спираль» | те же спринты | только если в центре **риск** |

Живой контраст трёх рисунков — в лабе на одном checkout.
