# 1. Тема

**Определение прототипа, класса**

---

# 2. Главное в одну фразу

Прототип — объект, из которого JavaScript ищет унаследованные свойства, а `class` — более удобный синтаксис для работы с тем же прототипным механизмом.

---

# 3. Суть

> «У каждого объекта есть внутренний прототип `[[Prototype]]`. Если свойство не найдено у самого объекта, движок идёт по цепочке прототипов до `null`.
>
> Классы не заменяют прототипы: методы экземпляров, написанные в теле класса, лежат в `Class.prototype` и разделяются всеми экземплярами. `class` добавляет удобный синтаксис конструктора, методов, `extends` и `super`.»

---

# 4. Самое главное запомнить

- Свойства экземпляра приоритетнее одноимённых свойств прототипа.
- Методы в прототипе не копируются в каждый экземпляр.
- `__proto__` устаревший аксессор; используйте `Object.getPrototypeOf`.
- Класс нельзя вызвать без `new`.
- Методы класса по умолчанию работают в строгом режиме.

---

# 5. Описание

```js
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return `Привет, ${this.name}`;
  }
}

const anna = new Person('Анна');
Object.getPrototypeOf(anna) === Person.prototype; // true
```

| Подход | Создание метода | Наследование |
|---|---|---|
| Конструктор + prototype | `Person.prototype.greet = ...` | `Object.create()` |
| `class` | метод в теле класса | `extends` |

Не кладите изменяемые массивы и объекты в общий прототип, если состояние должно быть индивидуальным: его разделят все экземпляры. Индивидуальные поля создавайте в конструкторе или полях класса.
