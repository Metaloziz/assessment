# 1. Тема

**Графы и связный список:** направленные · ненаправленные · узлы · рёбра · next

---

# 2. Главное в одну фразу

Связный список — цепочка узлов с указателем `next`; граф — набор вершин и рёбра между ними (с направлением или без) — оба задают «куда можно шагнуть», но граф допускает ветвления и циклы куда свободнее.

---

# 3. Суть

> **Связный список** хранит элементы не в непрерывном массиве, а в узлах: значение + ссылка на следующий (иногда ещё на предыдущий в двусвязном). Вставка/удаление рядом с известным узлом дёшевы, а доступ по индексу — дорогой проход с начала. Цикл в списке — отдельный класс задач (slow/fast).
>
> **Граф** — вершины и рёбра. В **ненаправленном** ребро двустороннее; в **направленном** (digraph) — только в одну сторону. Хранят обычно списком смежности (`Map` вершина → соседи) или матрицей. Обход: DFS (вглубь, стек/рекурсия) и BFS (вширь, очередь).
>
> Список — частный случай «очень худого» графа: у каждой вершины не больше одного исходящего ребра (и часто одного входящего). Ловушка: путать массив и список (индексация); в графе — забыть `visited` и зациклиться; в направленном — идти против стрелки.

---

# 4. Самое главное запомнить

- Список: узел `{ value, next }`; массив ≠ список.
- Доступ к i-му в списке ≈ O(n); вставка после известного узла ≈ O(1).
- Граф: V вершины, E рёбра; направленный vs нет.
- Список смежности — типичное представление; удобен для разреженных графов.
- DFS — стек/рекурсия; BFS — очередь; оба помечают посещённое.
- Цикл в списке / графе — нужен `visited` или slow-fast (для списка).
- Двусвязный список: ещё `prev` — проще удалять «из середины», зная узел.

---

# 5. Описание

## Связный список

### Картинка

```text
[1] → [2] → [3] → null
```

```typescript
type ListNode = { value: number; next: ListNode | null };

function fromArray(arr: number[]): ListNode | null {
  let head: ListNode | null = null;
  for (let i = arr.length - 1; i >= 0; i--) {
    head = { value: arr[i]!, next: head };
  }
  return head;
}
```

### Базовые операции

- **Пройти** — пока `node !== null`, шаг `node = node.next`.
- **Вставить после cur** — новый узел смотрит туда же, куда смотрел `cur`, затем `cur.next = новый`.
- **Удалить следующий** — `cur.next = cur.next.next` (нужен доступ к предыдущему).
- **Развернуть** — три указателя `prev / cur / next`, перекидываем ссылки.

```typescript
function reverse(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null;
  let cur = head;
  while (cur) {
    const next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }
  return prev;
}
```

### Цикл в списке

Два указателя: медленный +1, быстрый +2. Если есть цикл — встретятся.

## Графы

### Направленный и нет

```text
Ненаправленный          Направленный
  A ——— B                 A ──► B
  |     |                 ▲     │
  C ——— D                 └── C ◄┘
```

В ненаправленном «A связан с B» = можно идти в обе стороны (в списке смежности ребро кладут в оба списка). В направленном — только по стрелке.

### Представление: список смежности

```typescript
type Graph = Map<string, string[]>;

const undirected: Graph = new Map([
  ['A', ['B', 'C']],
  ['B', ['A', 'D']],
  ['C', ['A', 'D']],
  ['D', ['B', 'C']],
]);

const directed: Graph = new Map([
  ['A', ['B']],
  ['B', ['C']],
  ['C', ['A']],
]);
```

Матрица смежности `n×n` удобна, когда рёбер много и нужны быстрые проверки «есть ли ребро u→v» за O(1), но ест O(n²) памяти.

### DFS и BFS

**DFS (вглубь):** идём в первого соседа, пока не упрёмся, потом откат. Рекурсия или явный стек. Хорош для «есть ли путь», компонент, топосорта (в DAG).

**BFS (вширь):** очередь, уровень за уровнем. Кратчайший путь по числу рёбер в невзвешенном графе.

```typescript
function bfs(graph: Graph, start: string): string[] {
  const seen = new Set<string>([start]);
  const q = [start];
  const order: string[] = [];
  while (q.length) {
    const v = q.shift()!;
    order.push(v);
    for (const to of graph.get(v) ?? []) {
      if (!seen.has(to)) {
        seen.add(to);
        q.push(to);
      }
    }
  }
  return order;
}
```

Без `seen` / `visited` на графе с циклами обход не завершится.

### Связь списка и графа

Односвязный список — граф, где у каждой вершины ≤ 1 исходящего ребра. Поэтому приёмы вроде «два указателя» и «разворот ссылок» специфичны для списка, а DFS/BFS — общий язык графов (деревья, сетки, зависимости модулей).
