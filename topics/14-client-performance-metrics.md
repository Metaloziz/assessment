# 1. Тема

**Метрики клиентской производительности**

---

# 2. Главное в одну фразу

Клиентская производительность измеряется тем, как быстро страница становится видимой, интерактивной и стабильной — через Core Web Vitals и связанные метрики загрузки и отзывчивости.

---

# 3. Ответ для собеседования

> «Главные метрики — **Core Web Vitals**:
> - **LCP** ≤ 2.5 с — когда отрисован главный контент;
> - **INP** ≤ 200 мс — отзывчивость на клики/тапы;
> - **CLS** ≤ 0.1 — стабильность layout.
>
> Рядом: TTFB, FCP, TBT, long tasks, размер бандла.
> Lab (Lighthouse) ≠ Field (RUM/CrUX). FID заменён на INP.
> Оптимизируем причины: LCP-ресурс, меньше JS на критическом пути, размеры под медиа (CLS), меньше long tasks (INP).»

---

# 4. Самое главное запомнить

- Core Web Vitals = **LCP + INP + CLS**.
- LCP — «видно главное»; INP — «отзывчиво»; CLS — «не прыгает».
- Lab ≠ Field.
- FID устарел → INP.

### Что такое Core Web Vitals

Набор ключевых UX-метрик Google: скорость показа контента (LCP), отзывчивость (INP), визуальная стабильность (CLS).

---

# 5. Описание

| Метрика | Вопрос пользователя | Цель |
|---------|---------------------|------|
| LCP | Когда увидел главное? | ≤ 2.5 с |
| INP | Почему тормозит клик? | ≤ 200 мс |
| CLS | Почему кнопка уехала? | ≤ 0.1 |

Измерение: `web-vitals`, Lighthouse, PSI, CrUX, RUM.
