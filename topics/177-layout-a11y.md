# 1. Тема

**Доступность:** семантика · `tabindex` · ARIA · фокус

---

# 2. Главное в одну фразу

Доступность на фронте — сначала нативный HTML и видимый фокус, затем точечный ARIA; `tabindex` больше `0` почти всегда ломает порядок Tab.

---

# 3. Суть

> **Доступность (a11y)** — чтобы интерфейсом можно было пользоваться не только мышью: с клавиатуры, скринридером, при слабом зрении. В браузере это опирается на **accessibility tree**: роли, имена и состояния узлов, которые строятся из семантики HTML и при необходимости из ARIA.

> Зачем на практике: кастомный `<div onClick>` без роли и фокуса «работает» для мыши и молчит для Tab и VoiceOver. Пропавший `:focus` outline «красивее» дизайну и оставляет клавиатурного пользователя без ориентира. Юридически и продуктово (WCAG) это тот же UI, но для части аудитории — тупик.

> Как обычно закрывают базу. Берут **нативные** контролы (`button`, `a`, `input`, `label`) — роль и клавиатура уже есть. Имя берётся из текста, `<label>`, `alt` или `aria-label` / `aria-labelledby`. В порядке Tab участвуют интерактивные элементы с `tabindex="0"` или без атрибута; `tabindex="-1"` — только программный фокус. ARIA (`role`, `aria-*`) **дополняет**, когда натива не хватает (вкладки, диалог, live region), а не заменяет кнопку дивом с десятью атрибутами.

> Ловушка: `tabindex="1"` (и любой `> 0`) выдёргивает элемент из потока и путает весь документ. `outline: none` без своего `:focus-visible`. ARIA ради ARIA на уже семантичном теге. Иконка-кнопка без accessible name — для скринридера пустой контрол.

---

# 4. Самое главное запомнить

- Сначала семантика HTML; ARIA — когда натива не хватает.
- Accessible name: текст / `<label>` / `aria-label` / `aria-labelledby` (и `alt` у картинок).
- `tabindex="0"` — в естественный порядок Tab; `-1` — только из скрипта; `> 0` — почти всегда ошибка.
- Видимый фокус (`:focus-visible`) обязателен, если убрали дефолтный `outline`.
- `div` + `onClick` без `role="button"`, клавиатуры и фокуса — мышиный-only UI.
- Не дублировать роль: `<button role="button">` лишнее; неверная роль хуже её отсутствия.

# 5. Описание

```text
  мышь / Tab / скринридер
           │
           ▼
   DOM  →  accessibility tree  →  AT (VoiceOver, NVDA…)
           │
           ├─ роль (button, link, …)
           ├─ имя (name)
           └─ состояние (disabled, expanded, …)
```

## Семантика важнее декора

| Нужно | Берите | Избегайте |
| --- | --- | --- |
| Действие | `<button>` | `<div onclick>` |
| Навигация | `<a href>` | `<span onclick>` + роутер без клавиатуры |
| Поле | `<input>` + `<label>` | placeholder как единственная подпись |

Нативный контрол уже в Tab-порядке, активируется Space/Enter, озвучивается как кнопка/ссылка.

## `tabindex`

| Значение | Смысл |
| --- | --- |
| нет / `0` | в естественном порядке документа |
| `-1` | можно сфокусировать из JS (`el.focus()`), Tab пропускает |
| `> 0` | свой приоритет — ломает ожидание пользователя |

Типичный паттерн модалки: при открытии `focus()` на первый контрол или на контейнер с `tabindex="-1"`; Tab циклится внутри диалога; Esc закрывает.

## ARIA — коротко

- **`aria-label` / `aria-labelledby`** — имя, если текста нет (иконка «Закрыть»).
- **`aria-expanded` / `aria-controls`** — раскрывашка, меню.
- **`aria-hidden="true"`** — декоративное спрятать от AT (не на фокусируемом!).
- **`role="dialog"`** + подпись — кастомная модалка (лучше нативный `<dialog>` где можно).
- Live regions (`aria-live`) — статус после действия без переноса фокуса.

Правило: не ставьте ARIA, пока не проверили, что даёт сам тег.

## Фокус и видимость

```css
/* плохо */
.button { outline: none; }

/* лучше: своё кольцо для клавиатуры */
.button:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
```

`:focus-visible` показывает кольцо при клавиатуре и обычно не при клике мышью — удобный компромисс.

## Мини-пример

```html
<!-- ок: имя из текста, фокус нативный -->
<button type="button">Сохранить</button>

<!-- ок: иконка + имя -->
<button type="button" aria-label="Закрыть">
  <svg aria-hidden="true">…</svg>
</button>

<!-- плохо: нет роли, Tab, имени -->
<div class="btn" onclick="save()">💾</div>
```

## Ловушки

- Только мышь: ховер-меню без фокуса и Esc.
- `aria-label`, перекрывающий видимый текст, если они расходятся.
- Ловушка фокуса в виджете без возможности уйти на Tab/Esc.
- Контраст текста/иконок ниже WCAG — скринридер тут не спасёт.
