# 1. Тема

**IIFE**

---

# 2. Главное в одну фразу

IIFE — функциональное выражение, которое создаёт отдельную область видимости и немедленно выполняется.

---

# 3. Суть

> IIFE была распространённым способом изолировать переменные, передать зависимости и сохранить приватное состояние до появления ES-модулей и блочной области видимости. В современном коде для модульности обычно выбирают `import`/`export`, но IIFE остаётся важной для чтения старого кода и одноразовой инициализации.

---

# 4. Самое главное запомнить

- Скобки превращают `function` в выражение, а вторые скобки сразу его вызывают.
- Локальные переменные не попадают в глобальную область.
- Возвращённые функции сохраняют доступ к замкнутым переменным.
- В ES-модулях верхний уровень уже изолирован; IIFE там обычно не нужна.
- Передача глобальных объектов параметрами раньше помогала не зависеть от поиска имён и упрощала минификацию.

---

# 5. Описание

```js
const counter = (() => {
  let value = 0;

  return {
    increment: () => ++value,
    get: () => value,
  };
})();

counter.increment(); // 1
counter.get();       // 1
```

Имя полезно для стека вызовов:

```js
(function initializeAnalytics(window, document) {
  // локальная инициализация
})(window, document);
```

IIFE не делает данные «защищёнными» от всего процесса: она лишь ограничивает доступ через лексическую область. Если из IIFE вернуть объект или callback, он удерживает замкнутые данные в памяти. Не создавайте IIFE в горячем цикле только ради области видимости: это создаёт новые функции и контексты.
