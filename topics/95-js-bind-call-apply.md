# 1. Тема

**Подмена существующего контекста**

---

# 2. Главное в одну фразу

`call` и `apply` вызывают функцию сразу с заданным `this`, а `bind` создаёт новую функцию с закреплённым контекстом.

---

# 3. Суть

> У обычной функции `this` определяется способом вызова, поэтому переданный отдельно метод может потерять объект-владельца. `call`, `apply` и `bind` позволяют явно указать контекст.
>
> Это особенно нужно для методов в таймерах, обработчиках и чужих API: там функция вызывается не через исходный объект. Связанный контекст предотвращает ошибку, когда `this` оказывается `undefined` или другим значением.
>
> `call` вызывает функцию сразу с аргументами по одному, `apply` — сразу с массивом аргументов, а `bind` возвращает новую функцию для вызова позже. Стрелочная функция не подходит для такой подмены: её `this` берётся из внешней области в момент создания.

---

# 4. Самое главное запомнить

- `fn.call(ctx, a, b)` — немедленный вызов, аргументы по одному.
- `fn.apply(ctx, [a, b])` — немедленный вызов, аргументы массивом.
- `fn.bind(ctx, a)` — новая функция; аргументы можно частично зафиксировать.
- У стрелочной функции `call`, `apply` и `bind` не меняют `this`.
- При `new boundFn()` связанный `this` игнорируется: им становится новый экземпляр.

---

# 5. Описание

```js
function introduce(greeting, punctuation) {
  return `${greeting}, ${this.name}${punctuation}`;
}

const person = { name: 'Лена' };

introduce.call(person, 'Привет', '!');       // Привет, Лена!
introduce.apply(person, ['Здравствуйте', '.']); // Здравствуйте, Лена.

const greetLena = introduce.bind(person, 'Привет');
greetLena('!'); // Привет, Лена!
```

Частый случай — передача метода как колбэка. Метод теряет объект слева от точки, поэтому его нужно связать заранее.

```js
class Timer {
  constructor() {
    this.seconds = 0;
    this.tick = this.tick.bind(this);
  }

  tick() {
    this.seconds += 1;
  }
}
```

| Метод | Возвращает | Аргументы |
| --- | --- | --- |
| `call` | Результат функции | Списком |
| `apply` | Результат функции | Одним массивом |
| `bind` | Новую связанную функцию | Списком, допускает частичное применение |

В современном коде `apply` реже нужен для распаковки массива: вместо `fn.apply(ctx, args)` часто пишут `fn.call(ctx, ...args)`.
