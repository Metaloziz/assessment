# 1. Тема

**Определение контекста выполнения, случаи применения**

---

# 2. Главное в одну фразу

Контекст выполнения — окружение, которое создаёт JavaScript для запуска кода и определяет доступные переменные, функции и значение `this`.

---

# 3. Суть

> «При старте скрипта создаётся глобальный контекст, а при каждом вызове функции — отдельный функциональный. У контекста есть фаза создания: движок подготавливает объявления, параметры и `this`, затем фаза выполнения — выполняет инструкции по порядку.
>
> На практике важно отличать сам контекст выполнения от `this`: контекст хранит область видимости и состояние вызова, а `this` — одно из значений внутри него. В обычной функции `this` зависит от способа вызова, в стрелочной функции он берётся из внешнего лексического окружения.»

---

# 4. Самое главное запомнить

- Глобальный контекст создаётся один раз для скрипта или модуля.
- Каждый вызов обычной функции создаёт новый функциональный контекст.
- Контексты образуют стек вызовов: текущая функция завершается — управление возвращается к предыдущей.
- `this` определяется вызовом обычной функции, а не местом её объявления.
- Стрелочная функция не создаёт собственный `this`.

---

# 5. Описание

Контекст выполнения включает лексическое окружение с переменными и ссылкой на внешнюю область видимости, а также значение `this`. Во время создания доступны объявления `var`, `let`, `const`, функций и параметры; затем исполняются инструкции.

| Ситуация | Что происходит с `this` |
|---|---|
| `fn()` в строгом режиме | `undefined` |
| `obj.fn()` | `obj` |
| `new Fn()` | новый экземпляр |
| `fn.call(obj)` | `obj` |
| стрелочная функция | внешний `this` |

```js
const counter = {
  value: 0,
  increment() {
    this.value += 1;
    return this.value;
  },
};

counter.increment(); // 1
```

Для асинхронного коллбэка стрелочная функция сохраняет внешний `this`:

```js
const user = {
  name: 'Анна',
  showLater() {
    setTimeout(() => console.log(this.name), 100);
  },
};
```
