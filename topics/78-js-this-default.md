# 1. Тема

**Вычисление контекста, его значение по умолчанию**

---

# 2. Главное в одну фразу

У обычной функции `this` вычисляется в момент вызова, а значение по умолчанию зависит от строгого режима и среды выполнения.

---

# 3. Суть

> У обычной функции `this` не хранится в момент объявления. Его вычисляет конкретный вызов. В `user.greet()` это `user`, а в `greet()` — обычный вызов без объекта.
>
> Ошибка в этом правиле проявляется после передачи метода в коллбэк: он перестаёт вызываться через исходный объект. В строгом режиме у простого вызова `this` будет `undefined`, поэтому ошибка видна сразу; в старом нестрогом скрипте браузера — `globalThis`.
>
> `new` подставляет созданный экземпляр, `call` и `apply` задают значение на один вызов, а `bind` возвращает новую функцию с закреплённым `this`. Стрелочная функция своего `this` не получает: она использует внешний лексический.
>
> Не стоит объяснять правило «принадлежностью» функции объекту. Функция — значение; важна форма вызова в момент выполнения.

---

# 4. Самое главное запомнить

- ES-модули всегда работают в строгом режиме; верхнеуровневый `this` там `undefined`.
- В нестрогом обычном скрипте `this` при `fn()` — `globalThis`.
- У метода значение задаёт объект непосредственно перед точкой.
- `bind` возвращает новую функцию с закреплённым `this`.
- `call` принимает аргументы списком, `apply` — массивоподобным объектом.

---

# 5. Описание

| Вызов | `this` |
|---|---|
| `fn()` | `undefined` в strict mode, иначе `globalThis` |
| `user.fn()` | `user` |
| `new Fn()` | созданный экземпляр |
| `fn.call(user, x)` | `user` |
| `() => this` | внешний лексический `this` |

```js
'use strict';

function show() {
  return this;
}

show(); // undefined
show.call({ id: 1 }); // { id: 1 }
```

Отрыв метода от объекта меняет вид вызова:

```js
const user = {
  name: 'Анна',
  greet() { return this.name; },
};

const greet = user.greet;
greet(); // TypeError: this is undefined
```

Не стоит объяснять правило через «функция принадлежит объекту»: функция — значение. Значение `this` определяет именно конкретный вызов.
