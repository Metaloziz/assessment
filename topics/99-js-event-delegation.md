# 1. Тема

**Делегирование событий**

---

# 2. Главное в одну фразу

Один обработчик на общем предке может обрабатывать клики по множеству потомков благодаря всплытию.

---

# 3. Суть

> Делегирование событий — один обработчик на общем предке вместо обработчика на каждой дочерней кнопке. Оно работает потому, что событие после цели всплывает к контейнеру.
>
> Подход удобен для таблиц, меню и списков, где элементы появляются или удаляются динамически. Новый потомок сразу обрабатывается, поэтому не нужно отдельно регистрировать для него слушатель.
>
> В обработчике начинают с `event.target`, затем через `closest()` находят нужную кнопку или строку. Целью может быть вложенная иконка, поэтому точного сравнения часто недостаточно. Контейнер выбирают ближайший стабильный, а не весь `document`, и проверяют, что найденный элемент действительно принадлежит ему.

---

# 4. Самое главное запомнить

- Делегирование работает для всплывающих событий.
- `target` может быть вложенной иконкой, поэтому часто нужен `closest()`, а не точное сравнение.
- Проверяйте, что найденный элемент принадлежит контейнеру.
- Подходит для больших и динамических списков.
- Не вызывайте `stopPropagation()` без необходимости: оно может сломать делегированный обработчик выше.

---

# 5. Описание

```html
<ul id="tasks">
  <li data-task-id="1"><button data-action="remove">Удалить</button></li>
</ul>
```

```js
const tasks = document.querySelector('#tasks');

tasks.addEventListener('click', (event) => {
  const button = event.target.closest('[data-action="remove"]');
  if (!button || !tasks.contains(button)) return;

  button.closest('[data-task-id]').remove();
});
```

Обработчик сработает и для кнопки, которую добавили после регистрации. При клике на вложенный `<span>` `event.target` будет этим `span`, а `closest()` найдёт кнопку.

| Подход | Плюсы | Минусы |
| --- | --- | --- |
| Обработчик на каждом элементе | Прямой код | Нужно регистрировать для новых элементов |
| Делегирование | Меньше обработчиков, динамические потомки | Нужны фильтрация и всплывающее событие |

Выбирайте ближайшего общего предка: `document` технически работает, но делает обработку менее изолированной и увеличивает риск конфликтов.
