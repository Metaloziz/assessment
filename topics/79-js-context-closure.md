# 1. Тема

**Сохранение контекста выполнения через замыкание**

---

# 2. Главное в одну фразу

Чтобы вложенная функция использовала `this` внешнего метода, его можно сохранить в переменной замыкания или применить стрелочную функцию.

---

# 3. Суть

> Обычная вложенная функция не помнит `this` внешнего метода: она получает его по собственному вызову. Поэтому коллбэк таймера может потерять объект, состояние которого должен изменить.
>
> Это часто нужно в отложенных операциях, подписках и промисах, когда метод передаёт код браузеру или библиотеке. Без сохранения контекста счётчик, форма или экземпляр класса окажутся недоступны.
>
> Классический способ — записать внешний `this` в `const self` и использовать эту переменную: замыкание сохраняет к ней доступ. В новом коде обычно выбирают стрелочную функцию, которая берёт `this` из метода при создании. Для обычного коллбэка подходит `bind`.
>
> Стрелка не заменяет обычную функцию везде: если API специально передаёт свой `this`, например DOM-элемент обработчику, лексический `this` будет неверен.

---

# 4. Самое главное запомнить

- Замыкание хранит доступ к переменным внешней области видимости.
- `const self = this` сохраняет ссылку на объект, а не меняет `this`.
- Стрелка наследует `this` при создании, не при вызове.
- `bind` создаёт новую функцию — это важно для `removeEventListener`.

---

# 5. Описание

Классический вариант через замыкание:

```js
const timer = {
  seconds: 0,
  start() {
    const self = this;
    setTimeout(function () {
      self.seconds += 1;
    }, 1000);
  },
};
```

Современный вариант:

```js
const timer = {
  seconds: 0,
  start() {
    setTimeout(() => {
      this.seconds += 1;
    }, 1000);
  },
};
```

| Подход | Когда выбирать |
|---|---|
| `self = this` | поддержка старого кода, нужно объяснить замыкание |
| стрелочная функция | коллбэк должен использовать внешний `this` |
| `fn.bind(this)` | требуется передать обычную функцию с явной привязкой |

Стрелка не универсальна: не используйте её вместо метода объекта, если хотите, чтобы `this` зависел от вызывающего объекта.
