# 1. Тема

**Сохранение контекста выполнения через замыкание**

---

# 2. Главное в одну фразу

Чтобы вложенная функция использовала `this` внешнего метода, его можно сохранить в переменной замыкания или применить стрелочную функцию.

---

# 3. Суть

> «Обычная вложенная функция получает `this` по собственному вызову, поэтому она не помнит объект внешнего метода. Историческое решение — сохранить внешний `this` в `self` или `that`: вложенная функция замыкается на эту переменную.
>
> В современном коде чаще пишут стрелочную функцию: у неё нет собственного `this`, поэтому она лексически берёт его из метода. Если нужна именно обычная функция, можно использовать `bind`.»

---

# 4. Самое главное запомнить

- Замыкание хранит доступ к переменным внешней области видимости.
- `const self = this` сохраняет ссылку на объект, а не меняет `this`.
- Стрелка наследует `this` при создании, не при вызове.
- `bind` создаёт новую функцию — это важно для `removeEventListener`.

---

# 5. Описание

Классический вариант через замыкание:

```js
const timer = {
  seconds: 0,
  start() {
    const self = this;
    setTimeout(function () {
      self.seconds += 1;
    }, 1000);
  },
};
```

Современный вариант:

```js
const timer = {
  seconds: 0,
  start() {
    setTimeout(() => {
      this.seconds += 1;
    }, 1000);
  },
};
```

| Подход | Когда выбирать |
|---|---|
| `self = this` | поддержка старого кода, нужно объяснить замыкание |
| стрелочная функция | коллбэк должен использовать внешний `this` |
| `fn.bind(this)` | требуется передать обычную функцию с явной привязкой |

Стрелка не универсальна: не используйте её вместо метода объекта, если хотите, чтобы `this` зависел от вызывающего объекта.
