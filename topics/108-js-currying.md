# 1. Тема

**Каррирование**

---

# 2. Главное в одну фразу

Каррирование преобразует функцию с несколькими аргументами в цепочку функций, каждая из которых принимает часть аргументов.

---

# 3. Суть

> Каррирование превращает функцию с несколькими аргументами в цепочку вызовов, например `f(a)(b)(c)`. Каждый шаг возвращает функцию и через замыкание помнит уже переданные значения.
>
> Так удобно сначала настроить операцию, а затем много раз передавать данные: выбрать валюту и локаль для форматирования цен или создать обработчик для конкретного события. Промежуточной функции нужно давать понятное назначение.
>
> Каррированная оболочка накапливает аргументы и вызывает исходную функцию, когда их достаточно. Её следует писать аккуратно с `this`, значениями по умолчанию и rest-параметрами. Каррирование не равно частичному применению: `bind` фиксирует аргументы, но не обязательно создаёт цепочку одноаргументных вызовов.

---

# 4. Самое главное запомнить

- `f(a, b, c)` в каррированной форме вызывают как `f(a)(b)(c)`.
- Замыкание сохраняет ранее переданные аргументы.
- `fn.length` показывает число параметров до первого с default/rest-параметром, поэтому универсальный `curry` имеет ограничения.
- Каррирование удобно для композиции и настройки обработчиков, но не обязано улучшать читаемость.
- `this` нужно сохранять при универсальной реализации через `apply`/`call`.

---

# 5. Описание

```js
const multiply = (a) => (b) => a * b;

const double = multiply(2);
double(21); // 42
```

Универсальный вариант накапливает аргументы до арности исходной функции:

```js
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) return fn.apply(this, args);
    return (...next) => curried.apply(this, [...args, ...next]);
  };
}

const formatPrice = curry((currency, locale, amount) =>
  new Intl.NumberFormat(locale, { style: 'currency', currency }).format(amount)
);
const rubles = formatPrice('RUB')('ru-RU');
rubles(1200);
```

Не путайте с `bind`: `fn.bind(null, first)` — частичное применение, но не превращение всех параметров в цепочку одноаргументных функций. В прикладном UI каррирование оправдано, когда промежуточная функция имеет понятное имя и реально переиспользуется.
