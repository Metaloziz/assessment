# 1. Тема

**Псевдомассив arguments**

---

# 2. Главное в одну фразу

`arguments` — массивоподобный объект аргументов обычной функции, который в новом коде обычно заменяют rest-параметром.

---

# 3. Суть

> «`arguments` доступен внутри обычной функции и содержит все фактически переданные значения, даже если параметров в сигнатуре нет. У него есть индексы и `length`, но это не Array: методов `map` и `reduce` у него нет.
>
> Предпочитаю `...args`: это настоящий массив, он явно виден в сигнатуре и работает со стрелочными функциями. У стрелки собственного `arguments` нет — она видит только значение внешней обычной функции, если оно есть.»

---

# 4. Самое главное запомнить

- `arguments` есть только у обычных функций.
- Это не `Array`, но его можно преобразовать через `[...arguments]` или `Array.from`.
- В нестрогих простых функциях параметры и `arguments` могут быть связаны.
- Rest-параметр должен быть последним и всегда создаёт массив.

---

# 5. Описание

| Свойство | `arguments` | `...args` |
|---|---|---|
| Тип | массивоподобный объект | `Array` |
| Стрелочная функция | нет собственного | поддерживается |
| Методы массива | нет | есть |
| Видимость в сигнатуре | нет | да |

```js
function sum() {
  return [...arguments].reduce((total, value) => total + value, 0);
}

const sumModern = (...values) =>
  values.reduce((total, value) => total + value, 0);
```

`arguments` полезно знать для чтения старого кода и написания совместимых обёрток, но для новых API используйте rest-параметры.
