# 1. Тема

**Функции-фабрики**

---

# 2. Главное в одну фразу

Фабрика — обычная функция, которая создаёт и возвращает объект без вызова через `new`.

---

# 3. Суть

> Фабрика настраивает объект параметрами, а через замыкание может оставить часть состояния приватной. Каждый вызов возвращает новый объект.

---

# 4. Самое главное запомнить

- Фабрика возвращает объект явно.
- Для неё не нужны `new`, `this` и `prototype`.
- Замыкание даёт приватное состояние, недоступное через свойства объекта.
- Методы, созданные внутри фабрики, будут новыми для каждого экземпляра.
- Для большого числа экземпляров общие методы на прототипе могут быть экономнее.

---

# 5. Описание

```js
function createCounter(initialValue = 0) {
  let value = initialValue;

  return {
    increment() {
      value += 1;
      return value;
    },
    get value() {
      return value;
    },
  };
}

const counter = createCounter(5);
counter.increment(); // 6
console.log(counter.value); // 6
```

`value` нельзя изменить извне как `counter.value = 0`: он находится в замыкании, а API фабрики определяет допустимые операции.

```js
const createUser = (name, options = {}) => ({
  name,
  role: options.role ?? 'reader',
  canEdit() {
    return this.role === 'editor';
  },
});
```

| Подход | Создание | Приватные данные | Общие методы |
| --- | --- | --- | --- |
| Фабрика | `createUser()` | Через замыкание | Нужно вынести отдельно |
| Класс | `new User()` | Поля `#private` | На `prototype` |

Фабрики полезны, когда объект собирается из опций, имеет небольшое поведение или нужно скрыть состояние. Классы не обязательны для моделирования сущностей — выбирайте форму, которая делает API понятнее.
