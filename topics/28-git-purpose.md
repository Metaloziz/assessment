# 1. Тема

**Назначение системы Git**

---

# 2. Главное в одну фразу

Git — распределённая система контроля версий: хранит историю изменений, координирует командную работу и позволяет безопасно ветвиться, сливаться и откатываться.

---

# 3. Ответ для собеседования

> «**Git** — распределённая VCS: у каждого разработчика полная копия репозитория со всей историей.
>
> Назначения:
> - **контроль версий** — история изменений и откат;
> - **командная работа** — параллельные ветки и merge/rebase;
> - **авторство и аудит** — кто и что менял;
> - **разрешение конфликтов** при одновременном редактировании.
>
> Распределённость даёт офлайн-работу, быстрые локальные операции и целостность через хеши коммитов.»

---

# 4. Самое главное запомнить

- Git = распределённая VCS, не только «бэкап на GitHub».
- Полная история локально.
- Branching + merging — ядро workflow.
- Целостность через хеши.

### Ключевые возможности

- Ветвление и слияние
- Резервное копирование и восстановление
- Отслеживание авторства
- Резолвинг конфликтов

---

# 5. Описание

**Преимущества распределённой архитектуры:** полный локальный репозиторий, работа офлайн с последующей синхронизацией, целостность данных через хеширование.
