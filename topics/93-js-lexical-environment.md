# 1. Тема

**Лексическое окружение**

---

# 2. Главное в одну фразу

Функция помнит переменные из места, где была создана, а не из места, где её вызвали.

---

# 3. Суть

> У каждого выполняемого блока и функции есть набор локальных имён и ссылка на внешнее окружение. Эти ссылки образуют цепочку и делают возможными замыкания.

---

# 4. Самое главное запомнить

- Лексическое окружение определяется структурой кода при объявлении функций.
- Поиск имени начинается в текущем окружении и продолжается наружу.
- Замыкание хранит ссылку на переменную, а не её снимок.
- Каждый вызов функции создаёт своё окружение.
- `let` в цикле создаёт отдельное окружение для каждой итерации.

---

# 5. Описание

```js
function makeCounter() {
  let count = 0;

  return () => ++count;
}

const first = makeCounter();
console.log(first()); // 1
console.log(first()); // 2
```

После завершения `makeCounter` переменная `count` не исчезает: на неё всё ещё ссылается возвращённая функция. Другой вызов создаст независимый `count`.

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0); // 3, 3, 3
}

for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0); // 0, 1, 2
}
```

| Понятие | Значение |
| --- | --- |
| Лексическое окружение | Имена текущей области и ссылка наружу |
| Внешнее окружение | Область, в которой функция была объявлена |
| Замыкание | Функция вместе с доступом к внешним переменным |

Не стоит считать замыкание автоматически утечкой памяти: память удерживается, пока на функцию есть достижимая ссылка. Утечка возникает, например, если долго живущий обработчик удерживает большой ненужный объект.
